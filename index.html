「Webコンテンツ作成」の成果

本テーマについて

　このテーマの目的は、先行する情報工学の専門科目の基礎知識を応用して、実践的な能力を修得することです。HTML、CSS、JavaScriptの基本的な使い方を理解し、それらを組み合わせて簡単なWebページを作れるようになることがこのテーマの目標です。

プロジェクト課題について

　プロジェクト課題は世界の天気を選択しました。動きとしては都市名をプルダウンメニューから選んで検索ボタンを押すとその都市の天気に関する情報と天気のアイコンが表示されます。最初はあらかじめ手打ちしたデータを表示するページでしたが、JavaScript内にあらかじめ設定したデータを参照して表示できるようになったこと、またサーバーと通信して様々な都市のデータを表示できるようになった際は感動しました。またif文を使って天気のアイコンが変わるようにもしました。

プロジェクト課題で作成したページ:project.html

数当てゲーム

　数当てゲームは、ユーザーが入力した数値とランダム生成した数値を比較して一緒なら終了、違かったらヒントを表示しユーザーは3回以内に答えられたら勝ちというゲームです。今までの演習問題や課題と比べて書かないといけないコードが多くフローを見ながら丁寧にコーディングをしました。またコンソールを使ってからコードを書くという手法ですが、思ったより使いこなせなかったというのが感想です。なぜかというとまずコンソールでデータの入出力を確認して実際に動いた後、こんなことをしたら繋がるかなと思ったらVSコードにペーストしてそのまま記載してしまったことが原因として挙げられます。そのため作業手順を遵守する心がけも必要だと思いました。

演習の成果:数当てゲーム

各授業回の学習事項

第1回 WWWとHTML

　今回学習した内容は主にWebページに関する内容とHTMLについてです。Webページに関する内容ではWebページの構成やURLについて学びました。HTMLについては、HTMLを書くうえで重要となる要素の種類や属性の書き方、HTMLの構成、「<」などといった特殊な文字の書き方、コメントの仕方などのこれから作品を作る上で重要なことを学びました。

演習の成果: 演習1-4:HTMLのさまざまな要素

第2回 CSSによるWebページの装飾

　今回学習した内容はCSSについてです。CSSはWebページの見た目を変更する要素です。しかしデザインは多岐に渡るためさまざまなコーティング方法やプロパティがあり似ているプロパティでも意味や動きが全く違く、しっかり欠けていのに実は違うということが多くあるのが大変でした。

演習の成果: 演習2-3:ウェブブラウザの紹介

第3回 JavaScript の基本

　第1回目の授業ではHTMLについて学習しました。HTMLはWebページの基本的な構造を記述するもので、Htmlを書くときのポイントは見た目などは一切意識せずにタイトルだからh1タグ、段落を記述したいからpタグ、などといったように記述することです。第二回ではCssについて学びましたc。htmlに色などの装飾を加えるものがCssになります。Cssはどのような目的に合わせてさまざまなプロパティを組み合わせて目的のものを作ります。要素の色情報の他にも角度や余白、書体なども設定できます。第3回目ではjavascriptについて学びました。javascriptはWebページ上で動かすことができるプログライング言語です。そのため多岐にわたる種類や機能があります。javaという名前がついていますが、javaとは別物です。大きな違いとしてはjavaはコンパイルしてから実行するコンパイル言語ですがJavaScriptはコンパイルの手間がかからないインタプリタ言語です。また型の定義方法や使い方も違いがあり注意しながら作業をしました。またJavaScriptはjavaと違いエラーでもエラーとして実行が止まらないためデバッグが非常に重要です。

演習の成果:演習:3-6 JavaScript のオブジェクト

第4回 DOM と JavaScript

　今回の授業ではjavascriptをホームページに反映させるやり方などを学びました。前回の授業でもJavaScriptの勉強をしましたが、前回はJavaScriptをhtmlファイルに追加する方法やプロ1で習ったようなコンソールに変数を入れて計算や条件分岐などのやり方を学びました。今回はWebページのテキストの表示内容を変えたり、ユーザーが入力した文字を受け取ったりすることを行いました。それに伴いIDやNameを用いてhtmlの要素を指定する必要があります。Cssと書き方は同じはずですが、nameとIDの指定方法を逆に書いてエラーを数回出してしまったのでしっかりと復習しないといけないなと感じました。またjavaでは習ってないイベントというユーザーの何らかの操作や出来事を示すの理解が少し難しかったです。ですが実際に書いたコードが表示されるため達成感も味わえました。

演習の成果:演習:4-10 足し算ページ

第5回 イベント処理

　今回の授業ではhtmlを増やしたり消したりするコードの書き方を学びました。htmlは初回の授業での学習だったため一部の要素の意味などを忘れてしまっていてそこから復習する必要がありました。また今回の処理は非常に複雑でオブジェクトをhtmlに反映させるまでの間にCreateElmentで要素を作る、その要素にTextcontentで文字を入れる、そしてinsertAdjactElementで要素を配置してユーザに見えるようにするという工程があります。またul要素の中にあるli要素何なると理解にある程度時間がかかってしまいました。またIDが#でつかないことがありID=名前でつけないといけなかったのが個人的に復習が必要だなと感じました。

演習の成果:演習:5-7 DOM演習その2

工夫点、苦心点、強調点、感想

　このテーマの学習での工夫点はプロジェクト課題においてユーザーが一番知りたいと思っている天気を文字での表示に加えて、視覚的にもわかりやすいイラストを挿入したところです。またユーザーが欲しいと思われる天気や温度といった情報は大きくまた不要と思われる緯度や経度といった情報は比較的小さく表示することで、ユーザーがストレスなく直感的に閲覧できるように心がけました。 苦心点は、習ったこと全てがつながっているということです。当たり前ですが、ホームページはHTML、CSS、JavaScriptが組み合わさって出来ています。それによって前回の内容だからもう不要というわけには行きません。しかしHTMLやCSSに関してはプロジェクト課題を作っている最中やIndex.htmlを編集している最中にフォーマットが崩れてしまったり、機能の追加や修正に伴って再編集したりすることが複数回ありました。その度に私はそれぞれのHTMLやCSSを見ても何処が悪いかなどはなんとなくはわかったものの、すぐに手を動かすことが出来ず、思い通りに反映させられることができず、以前の資料や課題、例題などを見直して理解していました。他の科目の授業だと前回の内容と被りつつも新しい項目に進むなどと、全く新しい内容を行なって、日が空いた後に再びそのような内容を取り扱うということはあまりありませんでした。そのため前回までの内容を活かしながら行うところが少し大変に感じました。 強調点は使う色をできるだけまとめることによりユーザーが見やすくなるように心がけたところです。いろいろな色を使いすぎるとごちゃついて見える恐れがあるためできる限りシンプルにして見やすくなるようにしました。 最後にこのテーマではWebページの制作を通してプロジェクト課題や課題に取り組んできました。JavaScriptの学習が始まり出したあたりから、課題を解く時に一つ一つ小さな動きが動くことを確認してから書いていくことの大切さを実感しました。少し手間に感じることもかなりありました。しかしその小さい一つ一つの確認を重ねるごとにページの動きが目標の動きに近づけていくところに達成感を感じました。また講義資料の参考資料の欄に書いてあることを使わないと解けない問題が多々ありました、それにより資料をしっかりと隅々まで見て、その中からどれが今必要な情報でそれをどのように組み合わせたら作品を作ることができるのかを考えることができ、改めてしっかりと資料を読解してから物事に取り組むことの大切さを実感しました。
