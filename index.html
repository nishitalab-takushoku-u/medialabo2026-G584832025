各授業回の学習事項

第1回 WWWとHTML

今回学習した内容は主にWebページに関する内容とHTMLについてです。Webページに関する内容ではWebページの構成やURLについて学びました。HTMLについては、HTMLを書くうえで重要となる要素の種類や属性の書き方、HTMLの構成、「<」などといった特殊な文字の書き方、コメントの仕方などのこれから作品を作る上で重要なことを学びました。

演習の成果: 演習1-4:HTMLのさまざまな要素

第2回 CSSによるWebページの装飾

今回学習した内容はCSSについてです。CSSはWebページの見た目を変更する要素です。しかしデザインは多岐に渡るためさまざまなコーティング方法やプロパティがあり似ているプロパティでも意味や動きが全く違く、しっかり欠けていのに実は違うということが多くあるのが大変でした。

演習の成果: 演習2-3:ウェブブラウザの紹介

第3回 JavaScript の基本

第1回目の授業ではHTMLについて学習しました。HTMLはWebページの基本的な構造を記述するもので、Htmlを書くときのポイントは見た目などは一切意識せずにタイトルだからh1タグ、段落を記述したいからpタグ、などといったように記述することです。第二回ではCssについて学びましたc。htmlに色などの装飾を加えるものがCssになります。Cssはどのような目的に合わせてさまざまなプロパティを組み合わせて目的のものを作ります。要素の色情報の他にも角度や余白、書体なども設定できます。第3回目ではjavascriptについて学びました。javascriptはWebページ上で動かすことができるプログライング言語です。そのため多岐にわたる種類や機能があります。javaという名前がついていますが、javaとは別物です。大きな違いとしてはjavaはコンパイルしてから実行するコンパイル言語ですがJavaScriptはコンパイルの手間がかからないインタプリタ言語です。また型の定義方法や使い方も違いがあり注意しながら作業をしました。またJavaScriptはjavaと違いエラーでもエラーとして実行が止まらないためデバッグが非常に重要です。

演習の成果:演習:3-6 JavaScript のオブジェクト
